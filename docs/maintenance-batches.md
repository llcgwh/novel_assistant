## 第二批：JSON 备份关联完整性（2026-09-08）

- JSON 导出增加版本号、关系组和成员；恢复支持组的父子 ID 重映射，包含子组先出现的情况。
- 补齐场景、伏笔、大纲、时间轴、地图位置的标签恢复，以及场景关联地图位置的恢复。
- 在删除旧数据前检查必要分区、ID、引用和层级循环；拒绝不支持的备份版本。

- 保持旧版无版本号、无关系组备份可导入。恢复是替换操作：旧备份没有关系组时，目标小说的关系组也会被清空。

## 第三批：含图片备份与跨设备恢复（2026-09-08）

- 新增 GET/POST `/api/novels/{novelId}/backup`，设置页支持本地下载与恢复；WebDAV 使用新备份格式，仍可恢复旧 JSON。
- 单文件 JSON 封装小说数据、图片 Base64 内容和 SHA-256 校验值，不导出本地文件路径。限制每图 8 MiB、图片合计 32 MiB、备份 48 MiB、图片数量 1000。
- 恢复使用随机文件名和新图片 ID，改写封面/条目中的内部图片地址，恢复标题及描述等元数据；保留目标 WebDAV 配置。
- 数据库事务失败时删除新建文件，保留原图片和记录。成功后旧文件暂存于 uploads，后续再做孤立文件清理。
- 地图页从服务器图片列表找回背景；恢复成功刷新页面，避免继续使用旧 ID。外部图片不下载，浏览器偏好不迁移。
- 验证：Vue 生产构建通过；19 项后端测试通过，包含 H2 跨小说图片恢复、校验失败、回滚清理和 WebDAV 调用测试。未对真实 WebDAV 服务及 PostgreSQL 做端到端测试。

## 第四批：其余模块的小说归属校验（2026-09-08）

- 场景、伏笔、大纲、时间轴、地图、人物关系、关系组、世界观、标签和图片的按 ID 读取/修改/删除均校验目标小说；图片文件读取同样校验。
- 服务方法显式接收 novelId，共用 NovelScope 从数据库核验关联记录，拒绝伪造关联对象中的 novelId。
- 创建记录忽略客户端 ID；创建/更新及标签、成员、场景等批量关联在变更前检查引用，避免部分成功。
- 关系组基本信息和成员在一个事务内创建/更新；地图和关系组父级必须属于同一小说，并拒绝循环。
- 验证：44 项后端测试通过。其中新增 25 项 H2/MockMvc 测试覆盖十个模块的跨小说 HTTP 访问、客户端 ID、嵌套伪造、混合批次和正常关联。
- 本批没有自动扫描或清理历史错误关联，也没有操作真实 PostgreSQL 数据。

## 第五批：WebDAV 密码加密与明文迁移（2026-09-08）

- JPA 转换器统一加解密，数据库使用 AES-256-GCM 密文及随机 nonce；密码列扩大为 TEXT。
- 默认密钥保存在工作目录的 `.secrets/webdav.key`，POSIX 系统新建权限 0600；支持环境变量提供密钥或固定路径，密钥不进 Git 或小说备份。
- 启动迁移先校验已有密文，再事务迁移旧明文；可重复执行。缺失/错误密钥或损坏数据会报错，不覆盖旧值。
- 新增 `database/migration_v4.sql` 和 [密码存储说明](credential-storage.md)，说明升级、密钥保管及故障处理。
- 验证：53 项后端测试通过。新增 9 项测试覆盖密钥持久化、随机密文、篡改/错钥/丢钥、原始数据库列、Unicode 密码及明文迁移。没有执行真实 PostgreSQL 数据迁移。

## 第六批：编辑弹窗防重复提交与标签失败重试（2026-09-11）

- 人物、场景、伏笔、大纲、时间轴、地图的主编辑弹窗增加提交锁；请求期间禁用表单与默认操作按钮，点击遮罩不会关闭弹窗。

- 失败后释放提交锁，允许重试；成功后关闭弹窗。此次未增加依赖。

- 移除布局重复设置小说 ID 的逻辑；列表标题加载失败不再影响点击事件监听器的注册。
- 验证：`cd frontend-vue && node --test tests/*.test.mjs` 共 25 项测试通过（本批新增 8 项，使用真实 Vue Router、Pinia 和 Axios，替换 HTTP 传输与浏览器存储）；Vue 类型检查和生产构建通过。未进行浏览器及真实后端端到端测试。
