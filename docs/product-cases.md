## 批次与依赖

1. **创作接力与修订基础**：C06，C04/C05 的结构化任务、阅读书签、段落跳转。独立保存版本，作品隔离、失败重试、备份、拆合章锚点迁移先完成。
2. **修订与阅读深化**：C04 的差异比较、逐段采用与轮次，C05 的全书连续／分页；C11、C12 逐项接入。
3. **结构可视化**：C03，带动 C15/C16 和 C17；不让特效阻碍写作和定位。
4. **故事状态与秘密**：C01 → C02 → C05 知情范围；先作者显式记录，再增加可解释的规则提示。
5. **分支、系列与交稿**：C07、C08、C13、C14；分别验证字数、资料引用和作品隔离。
6. **离线与长期同步**：C09、C10 依据数据模型稳定程度分批实施，避免与前述迁移相互覆盖。

核心创作流程不依赖付费 AI。需要模型推断的能力若另行提出，必须与作者已确认的事实区分。
