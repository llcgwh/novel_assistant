## 交付边界

操作说明见 [写作指南](writing-guide.md)。离线支持已打开章节的浏览器草稿；云端冲突需比较或保留副本，不自动合并文本；自动同步需要后端运行；Markdown 导入以文本和章节识别为主。历史界面展示最近 100 条，完整备份带最近 2,000 条；远端版本不自动清理；同步结果摘要不等于永久操作流水。人物识别、登场足迹和伏笔检查基于明确资料/关联，不是剧情语义分析。已验证 WsgiDAV，不代表已逐家验证云盘/NAS 的实现差异。

代码按正文基础、WebDAV/搜索、保存保护、前端整合和文档分批提交并推送。正文基础为 `dd49caf`，同步基础为 `4828a49`，手动存档修复为 `ed5b1d7`，前端与总览切换修复为 `82fd87b`。

保留已有 package/devtools/Sass、IDE 和构建缓存本地改动。使用独立测试库，不修改用户小说库。本轮按用户要求保留验收服务运行，虚构长篇与日历记录仅用于验收。

编辑器依据 [Tiptap Vue 3](https://tiptap.dev/docs/editor/getting-started/install/vue3) 与 [UniqueID](https://tiptap.dev/docs/editor/extensions/functionality/uniqueid) 官方接口实现；无需云端编辑器服务。
