# 写作方案逐项核对

核对日期：2026-09-27。范围对应最初确认的八组写作方案，并记录这次追加的书架转场、署名、README 和日历要求。以下区分已实现能力与产品边界，不把“存在入口”当作全部语义都已实现。

## 1. 作品、篇卷、章节管理

**已实现**：作品 → 篇卷 → 章节；未分卷章节；新建、重命名、拖动/按钮排序、跨卷移动、复制、拆章、合章、回收站；序章等可关闭编号；草稿、写作中、待修订、定稿状态；摘要和字数目标。大纲与正文独立保存，大纲可创建章节，也可与既有章节关联，一条大纲可对应多章。

正文、资料、统计、草稿键和同步身份按作品隔离。拆合章会迁移段落关联，结构修改带版本检查。篇卷删除保留正文；章节删除先进入回收站。

## 2. 编辑器与可靠保存

**已实现**：富文本、撤销重做、章节查找替换、全书搜索、字体/字号/行距/缩进/阅读宽度、专注模式、打字机滚动、段落聚焦与手机编辑。浏览器 IndexedDB 草稿、服务端自动/手动保存、历史比较恢复，以及多窗口版本冲突比较与副本保护均已接入。

**边界**：离线支持已打开章节的继续编辑，不包含完整应用离线启动或未缓存章节浏览。历史界面展示最近 100 条，完整备份携带最近 2,000 条。排版偏好保存在本浏览器；冲突比较为两份稿件并列查看，不自动逐字合并。单章正文 JSON 上限 2 MiB。

## 3. 随正文变化的资料侧栏

**已实现**：中文输入完成后识别当前段落姓名/别名，显示头像、身份、性格、外貌、背景与关系；同名保留候选，可忽略或固定。正式关联由作者确认，支持章级或稳定段落标识。时间线显示事件、相关人物/场景、前后事件；场景与地点显示资料和图片；八类资料均有回到正文的入口。

一章可绑定多个事件，故事顺序与叙述顺序分离；章节改名和排序不会改变段落关联。原段落已删除时提示失效，仍能打开章节。

**边界**：人名识别是本地文字匹配，不推断代词或隐藏身份；固定与忽略为当前工作区状态，别名随作品保存。事件前后顺序以时间线的故事排序为准，不解析任意自然语言日期。

## 4. 主动创作工具

| 原约定 | 当前实现 |
| --- | --- |
| 选文收进世界 | 可创建人物、伏笔、场景、设定或修订便签，保留章节/段落与所选原文。 |
| 人物登场足迹 | 档案显示关联章节及首末登场；按篇卷/章节/段落叙述顺序，仅统计明确关联，失效段落不计首末。 |
| 伏笔回收账 | 区分计划用途与已记录用途，可勾选完成/撤回，显示本章计划、已处理及涉及的待回收线索。 |
| 本章创作卡 | 汇总目标字数、创作目标、视角人物、场景地点、大纲、此刻事件与待办。 |
| 章节关系视图 | “故事回响”按共同资料筛选串联章节并跳转，采用列表呈现。 |

**边界**：这些提示依据显式关联、资料状态和待办勾选，不验证剧情逻辑，也不自动判断伏笔是否已被文字揭示。日常功能无需调用付费 AI。章节串联列表不等于可自由拖拽的全书网络图。

## 5. 码字统计

**已实现**：最近 60 秒手输速率、本次完整窗口峰值、手输/粘贴/净增、活跃时间、暂停与空闲暂停、当前章/卷/全书总字数、今日平均速率/净增/目标、365 天热力日历，以及含标点字符数副指标。

中文友好字数按汉字、英文词、连续数字组统计，不计标点空白；含标点字符数按 Unicode 字符统计但不计空白。粘贴不抬高速率，撤销、替换、恢复不冒充新手输；会话用稳定标识和序号去重，跨日另起统计。

**边界**：净增可以为负，活跃时间采用输入间隔规则，并非键盘硬件计时。每日日期按写作设备的本地日期记录；同一内容另起会话重新输入仍算新的写作行为。热图颜色按当前每日目标分档，修改目标会重新着色，不改历史计数。

## 6. WebDAV 整部作品同步

**已实现**：稳定作品身份与独立目录，正文、结构、资料、段落关联、图片、别名、统计和必要历史一起备份；自动检查上传、失败后续重试、远端版本发现、全文比较、分支冲突保护。采用远端前保存本机整部作品副本；旧无正文备份禁止静默覆盖已有文稿。

**已补齐 C10**：设置页提供永久操作记录、失败阶段与安全详情、远端占用，以及按最新份数／远端修改时间配置的保留策略。清理先列出拟删除与保留文件，再由作者勾选确认；保留恢复基线、分支头和版本连接信息。预览失效、目录变化、重复请求与多设备并发均有保护，恢复前保留完整副本。

**有明确限制**：自动同步需要后端持续运行，约每五分钟检查；不会自动用远端覆盖本机，也不自动合并两份正文。操作流水属于当前服务数据库，不汇总另一台独立服务器的日志，也不随作品恢复回退。远端历史不自动删除，共享旧版备份全部保留；不能提供有效独占锁或强校验条件的 WebDAV 拒绝清理。旧备份恢复到新作品时不会凭空补出正文。已验证本地 WsgiDAV，未逐家验证所有云盘/NAS。

## 7. 导出与旧稿导入

**已实现**：单章、选定章节、篇卷、全书范围；真实 DOCX、UTF-8 TXT、Markdown。Word 支持标题层级、篇卷、标题页、目录域、分页与常用富文本。可选创作附录包含实际人物卡、伏笔说明、其他关联资料和笔记，查询限定当前作品，失效项明确标记，默认不包含。完整 JSON 备份用于恢复资料、关联、计划和历史。

TXT/Markdown 导入可识别章标题、预览拆分、改名和指定篇卷，导入当前选中的作品，不覆盖旧章。

**边界**：Markdown 导入主要处理文本和章标题，不保证富文本格式完整往返；暂不支持 Word 文件导入。Word 目录域需在 Word 中更新。导入文件上限 4 MiB；含图片备份上限为单图 8 MiB、图片合计 32 MiB、文件总计 48 MiB。

## 8. 工作室整合与本次视觉追加

**已实现**：写作页以篇章目录、正文、右侧故事罗盘和底部统计组成；资料页签延续翻转效果，持续输入不触发整页翻转。书架和总览显示正文进度与继续写作，全局搜索包含正文并可定位命中位置。

本次补充书架进入作品、返回书架的双向书封翻页；目标位置预留空位，书封与真实折页内容在翻面中接替，落位后恢复交互。减少动态效果和关闭空间动态时跳过。常驻小型 llcg 署名连接作者 GitHub、项目仓库与邮箱。README 整理功能、启动、指南及 Claude/DeepSeek/GPT 的阶段贡献；旧原生前端已移除，当前前端仍为 `frontend-vue/`。

日历改为 365 天周网格，绿色深浅表示正净增，橙色纹理表示净减少；悬停、聚焦、点击与键盘移动均提供每日详情。手机可横向浏览，正文统计和页面内容预留署名空间。

## 验证与长篇实测

断网草稿、跨作品隔离、请求丢失重试、同步冲突、拆合章节和真实导出有专项回归；本轮验证记录见 [实施记录](writing-implementation.md)，操作见 [写作指南](writing-guide.md)。

独立测试库的合成长篇为 **120 章、96 万汉字**，工作区摘要响应约 **89 KB**，不一次载入全书正文。本机 HTTP 请求中位耗时：工作区 2.63 ms、单章读取 0.86 ms、章节保存 5.15 ms、全书搜索 20.28 ms、整书 TXT 19.87 ms。脚本还检查内容完整、章节顺序、选定导出范围及书架汇总一致。

这些数字是本机该批数据与运行环境的测量，不是浏览器输入延迟或服务性能承诺；网络、多设备并发、图片数量、不同机器和超长单章均会影响实际体验。复现入口为 `scripts/writing-performance-check.py`，仅允许独立集成测试环境。
